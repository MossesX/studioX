# Firecrawl

Web-data workbench over the Firecrawl API: multi-step workflows that search, scrape and map the live web, hand results to Fireball Freddy for plain-english AI analysis, loop over the links he picks, and land everything in exportable JSON/markdown datasets.

## Where it is

- Route: `/firecrawl`
- Module id: `firecrawl` — contributions target it as `module:firecrawl`
- Glyph: `icon-globe`

## What it publishes

- No extension points: nothing plugs into this module.

## Surfaces

- Context areas: `firecrawl.workflow`, `firecrawl.step`, `firecrawl.dataset`, `firecrawl.surface`
- Settings: 4 row(s) under `firecrawl-settings`
- Navigation: none declared
