# Dashboard

The landing screen: six live cards (nav tiles, modules, theme, packs, clock) on a free-placement grid, inside whichever dashboard wrapper is active.

## Where it is

- Route: `/`
- Module id: `dashboard` — contributions target it as `module:dashboard`
- Glyph: `icon-grid`

## What it publishes

- No extension points: nothing plugs into this module.

## Surfaces

- Context areas: `dashboard.grid`
- Settings: 1 row(s) under `dashboard-settings`
- Navigation: none declared
