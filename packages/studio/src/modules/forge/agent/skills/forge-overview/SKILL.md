# Forge

The agent, skill, tool and MCP designer over the full roster: the house set the studio ships, the repo's own .claude/, and your home directory's — created, edited, enabled, disabled and (for MCP servers) launched and handshake-tested from one screen.

## Where it is

- Route: `/forge`
- Module id: `forge` — contributions target it as `module:forge`
- Glyph: `icon-bolt`

## What it publishes

- No extension points: nothing plugs into this module.

## Surfaces

- Context areas: `forge.surface`
- Settings: 1 row(s) under `forge-settings`
- Navigation: none declared
